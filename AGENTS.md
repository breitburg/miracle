# Rules

1. **No backward compatibility.** The project is early. When something
   changes, remove the old code, APIs, and data completely. No shims,
   deprecation paths, or migrations.
2. **Bump, do not work around.** If a newer version of a library or framework
   has what we need, raise the minimum version and use it.
3. **Always the latest.** Use the newest stable libraries, frameworks, and
   toolchains, and their newest features and APIs.
